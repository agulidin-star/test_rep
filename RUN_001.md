## 1. Открытие в Android Studio

1. Скачай Android Studio Hedgehog или новее.
2. **File → Open** → выбери корневой каталог проекта (где лежит `settings.gradle.kts`).
3. Дождись завершения индексации и первого билда, который автоматически запустит Gradle.
   (Если потребуется, выбери **File → Sync Project with Gradle Files**.)

## 2. Сборка Debug APK

```bash
# Из корня проекта:
./gradlew assembleDebug
```

### Почему могут не собираться сразу

При первом запуске Gradle скачивает зависимости из `mavenCentral()` / `google()`.
Для коннекта к сети может понадобиться HTTP-прокси — настрой его в
`~/.gradle/gradle.properties`:

```properties
systemProp.http.proxyHost=<proxy>
systemProp.http.proxyPort=<port>
systemProp.https.proxyHost=<proxy>
systemProp.https.proxyPort=<port>
```

### Возможные ошибки на этапе сборки

| Сообщение | Причина | Исправление |
|---|---|---|
| `SDK location not found` | нет `local.properties` | создай его: `sdk.dir=~/Android/Sdk` |
| `Could not find method ksp()` | старый GradlePlugin | убедись что `org.jetbrains.kotlin.plugin.ksp` подключен в `build.gradle.kts` |
| `TaskEntity : class not found` | нет `ksp` анатации | файл верный, перезапусти билд |
| `faces.dat.rend` или другие | редкие | очисть кеш `./gradlew clean` |

## 4. Обновление виджета Glance

Виджет хранит последние (до 5) невыполненные задачи, отсортированные по дедлайну.
Он автоматически обновляется:
- после каждого изменения задачи в БД,
- раз в 60 минут через `PeriodicOverdueWorker`.

Вручную запустить обновление через ADB:

```bash
adb shell am broadcast -a android.appwidget.action.APPWIDGET_UPDATE \
  --ei appWidgetId <id>
```

## 5. Уведомления

Для Android 13+ требуется разрешение `POST_NOTIFICATIONS` (запрошено в манифесте,
запрашивается в UI при первом включении напоминаний).
